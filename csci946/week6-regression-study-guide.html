Part I · 回归是什么

Slide 3 用两句话划出了分界线:

回归分析想回答什么

Slide 3 还给出了回归分析的目的:explain the influence that a set of variables has on the outcome of another variable of interest——解释一组变量对另一个我们关心的变量(outcome)有多大影响。

注意这句话里的重心不只是"预测"。讲师的解释是:"We want to see how much variation of the output variable can be explained, can be modeled by this set of input variables." 回归有两个用途,一个是预测(给定输入,输出是多少),另一个是解释(哪些输入真正起作用、作用多大、方向是正是负)。后面读 R 输出时你会看到,大部分内容都在服务第二个用途:系数是否显著、模型解释了多少变异。

与神经网络的联系

Slide 3 的最后一条:single layer MLPs with linear activation function are linear regression methods。讲师解释:单层感知机做的事情 "is just an inner product between input variables and the weights, plus a bias"——输入与权重做内积再加一个偏置。如果激活函数是线性的(也就是不做任何变换),那它算出来的就是 β0+β1x1+…\beta_0 + \beta_1x_1 + \dots,与下面要讲的线性回归方程一模一样。线性回归可以看成最简单的神经网络。

Part II · Linear Regression

§2 线性回归模型:一条直线,加一点噪声

定义与用例

Slide 4 的定义:Linear regression is an analytical technique used to model the relationship between several input variables and a continuous outcome variable——用来建模若干输入变量与一个连续输出变量之间关系的分析技术。

它有一个关键假设 (key assumption):这种关系是线性的。Slide 上还加了一个括号——linear w.r.t. coefficients(对系数线性)。这个括号很重要,但讲师刻意把解释推迟到了诊断部分;我们先按直观理解"输出与输入成线性关系",到 §9 再揭开它的真实含义。

Slide 5 列了三类典型用例,每一类都是"一个连续输出 + 一堆可能影响它的输入":

领域 输出 (outcome) 输入 (input variables)
Real estate 房地产 房价 居住面积、卧室数量、学区排名、犯罪率……
Demand forecasting 需求预测 顾客会消耗的食物量 天气、星期几、折扣……
Medical 医疗 治疗效果 疗程长短、剂量、病人特征……

模型方程

Slide 6 写出了模型:

y=β0+β1x1+β2x2+…+βp−1xp−1+εy = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_{p-1} x_{p-1} + \varepsilon

逐个符号拆开:

  • yy 是 outcome variable(输出变量),必须是连续的。讲师:"the output Y, it must be a continuous variable."
  • xjx_j(j=1,2,…,p−1j = 1, 2, \dots, p-1)是 input variables(输入变量),也叫 feature 或 attribute。讲师特意说明输入可以是连续的,也可以是类别型的(类别型怎么放进方程,见 §8)。
  • β0\beta_0 是 intercept(截距),讲师也叫它 bias 或 offset:"the value of Y while all the X becomes zero." 所有输入都为 0 时,yy 的值就是 β0\beta_0。
  • βj\beta_j 是 coefficient(系数):"the change in y based on a unit change in xjx_j"——xjx_j 增加 1 个单位,yy 平均变化 βj\beta_j。讲师补充了一个必须带上的条件:"given that all the other attribute value keep as they were"——其他输入保持不变。βj\beta_j 可正可负,正号表示 xjx_j 越大 yy 越大,负号相反。
  • ε\varepsilon 是 random error term(随机误差项):"represents the difference in the linear model and a particular observed value for y"——线性模型的预测值与某一次实际观测值之间的差。

注意参数的下标:输入从 x1x_1 到 xp−1x_{p-1},共 p−1p-1 个,加上截距 β0\beta_0,模型一共有 pp 个参数。这个记号在后面读 R 输出里的"自由度"时会用到。

为什么要有 ε\varepsilon:非确定性

Slide 4 的第三条说线性回归是 non-deterministic(非确定性) 的:它 accounts for the randomness in an outcome(承认输出里有随机性),并且 provides the expected value of the outcome(给出输出的期望值)。

为什么要承认随机性?想象两套房子,面积、卧室数、学区、犯罪率全部一样,它们的成交价也不会分毫不差——买家的心情、谈判的技巧、成交那天的天气,无数个没被记录的因素都会让价格上下浮动。讲师的说法是观测值 "could be contaminated by noise",被噪声污染了。

所以模型把 yy 拆成两部分:

y⏟观测值=β0+β1x1+…+βp−1xp−1⏟线性模型能解释的部分+ε⏟解释不了的随机噪声\underbrace{y}_{\text{观测值}} = \underbrace{\beta_0 + \beta_1 x_1 + \dots + \beta_{p-1}x_{p-1}}_{\text{线性模型能解释的部分}} + \underbrace{\varepsilon}_{\text{解释不了的随机噪声}}

线性模型本身只负责前一半。它给出的不是"这套房子一定卖多少",而是"这类房子平均卖多少"——这就是 slide 说的 expected value(期望值)。讲师:"Once we have randomness, we really need to talk about the expected value." 这个想法到 §4 会被正式化。

§3 怎么求 β:Ordinary Least Squares

关键问题

方程写好了,可 β0,β1,…,βp−1\beta_0, \beta_1, \dots, \beta_{p-1} 都是 unknown(未知的)。Slide 7 抛出的就是这个 key question:怎么得到它们的值?

讲师的说法:"Given a training set... how do we estimate the beta0, beta1, ..., beta p minus 1? Once we know this beta value, we know the model. That's all." 训练集里每一条数据既有输入 xx,也有观测到的输出 yy。一旦把 β\beta 定下来,模型就完全确定了。

目标:让预测尽量贴近观测

什么样的 β\beta 算"好"?Slide 8 给出了标准:估出来的参数应该让模型 provide a reasonable estimate of the outcome variable,也就是让以下两者之间的总体误差最小:

  • 线性回归模型预测出来的值;
  • 实际收集到的观测值。

讲师的推理很直接:"Our purpose of linear regression is to predict. Certainly, we hope that our model can predict accurately." 预测要准,就得让预测值与真实值的差距尽量小。

对第 ii 条训练数据,观测值与预测值之差叫 residual(残差):

ei=yi−ŷi=yi−(β0+∑j=1p−1βjxij)e_i = y_i - \hat{y}_i = y_i - \left(\beta_0 + \sum_{j=1}^{p-1} \beta_j x_{ij}\right)

这里 ŷi\hat{y}_i(读作 "y hat")表示模型对第 ii 条数据的预测值,xijx_{ij} 是第 ii 条数据的第 jj 个输入。

OLS 的目标函数

Slide 9 介绍了最常用的估计方法 Ordinary Least Squares (OLS,普通最小二乘法):find the line best approximating the relationship——找一条最能逼近这种关系的直线。它的目标函数是:

minβ0,…,βp−1∑i=1N(yi−(β0+∑j=1p−1βjxij))2\min_{\beta_0, \dots, \beta_{p-1}} \sum_{i=1}^{N} \left( y_i - \left(\beta_0 + \sum_{j=1}^{p-1} \beta_j x_{ij}\right) \right)^2

用文字读出来:对 NN 条训练数据,把每条的残差平方后加起来,找让这个总和最小的那组 β\beta。 这个总和叫 sum of squared errors (SSE,残差平方和)。

为什么要平方?讲师的回答是:"because it could be larger than yiy_i or smaller than yiy_i"——残差有正有负,直接相加会正负抵消。一条把一半点高估 10、另一半点低估 10 的直线,残差之和恰好是 0,看起来"完美",实际上处处都错。平方之后全部变正,不会再抵消。

📎 拓展(超出 slides) — 用绝对值 |ei||e_i| 也能避免抵消,为什么偏偏选平方?两个原因。第一,平方函数处处可导,对 β\beta 求导后令其为 0 就能解出闭式解(见下文);绝对值在 0 点不可导,求解麻烦得多。第二,平方对大误差惩罚更重(误差 10 的代价是误差 1 的 100 倍),这让 OLS 拼命避免大错——这也是 §10 说"linear regression is sensitive to outliers"的根源:一个离群点的残差平方会非常大,把整条直线拽过去。

一维的几何图像

Slide 9 配了一张只有一个输入的图:横轴是 xx,纵轴是 yy,圆点是训练数据,斜线是 OLS 模型。每个点到直线有一条竖直的线段,标着 "Distance of datapoint to model"。这时目标函数简化为:

minβ0,β1∑i=1N(yi−(β0+β1xi))2\min_{\beta_0, \beta_1} \sum_{i=1}^{N} \left( y_i - (\beta_0 + \beta_1 x_i) \right)^2

讲师这样描述 OLS 在做的事:"We want to adjust this straight line, its direction and its intercept, to ensure the sum of the squared distance to be smallest." 想象手里拿着一根可以旋转、可以上下平移的直尺(斜率 β1\beta_1 管旋转,截距 β0\beta_0 管平移),在散点上来回调整,直到所有竖直线段的长度平方和最小——停下来的位置就是 OLS 直线。

注意这里量的是竖直距离,不是点到直线的垂直距离。因为我们的目的是预测 yy,误差就是 yy 方向上的偏差。

§4 再加一条假设:正态误差模型

OLS 没说 ε 是什么样子

回头看 §3,OLS 自始至终只是在"最小化平方误差",它对 ε\varepsilon 长什么样一个字也没说。Slide 10 点明了这一点:OLS makes no assumptions about the error term.

讲师说这既是 OLS 的优点,也是它的短板:"If we don't make any assumption about the error term, actually it prevents us to do more important statistical analysis." 不对误差做任何假设,我们就只能拿到一组 β\beta 的数值,却没法回答下面这些问题:

  • 这个 β̂1=0.6\hat\beta_1 = 0.6 有多可靠?换一批数据还会是 0.6 吗?
  • β1\beta_1 会不会其实是 0,只是这批数据碰巧让它看起来不是 0?
  • 预测值的误差范围有多大?

这些都是统计推断的问题。回忆 Week 3 的假设检验:做 t 检验之前,我们总要先假设数据服从正态分布、样本相互独立,然后才能算 t 值、查 p 值。讲师正是这样类比的:"when we discuss the hypothesis test, I always say we assume that it is a normal distribution, we assume the independence... In order to do hypothesis test... we also need to make additional assumption."

额外假设:误差服从正态分布

所以 Slide 10 说,常用的 linear regression model 在 OLS 的基础上 makes additional assumptions(做了额外假设),这些假设 provide further capabilities(提供了更多能力),而且 are almost always made(几乎总是会做)。

Slide 11 写出了这条额外假设。模型方程一个字都没变,只多了最后一行(slide 上用粗体标出):

y=β0+β1x1+…+βp−1xp−1+ε,𝛆∼𝐍(𝟎,𝛔𝟐),且各个 ε 相互独立y = \beta_0 + \beta_1 x_1 + \dots + \beta_{p-1}x_{p-1} + \varepsilon, \qquad \boldsymbol{\varepsilon \sim N(0, \sigma^2)}\text{,且各个 } \varepsilon \text{ 相互独立}

拆成三层意思:

  1. 零均值:ε\varepsilon 的平均值是 0。噪声没有系统性偏向,不会总把 yy 往上推或往下拉。
  2. 常数方差 σ2\sigma^2:无论 xx 取什么值,噪声的波动幅度都一样大。小房子和大豪宅的价格噪声幅度相同。
  3. 相互独立:讲师的解释是 "for different training data, they are independent of each other. They are not related." 这一条数据的噪声不影响另一条。

讲师特别澄清了"能力"的含义:"Capability means we have more understanding about the certainty, uncertainty, reliability about our estimate." 他还强调了一个容易混淆的点:"Although the beta value is calculated in the way of OLS, but to analyze the uncertainty of this beta value, we always make this additional assumption." β\beta 的数值仍然用 OLS 算,正态假设只是让我们能进一步评估这些数值的可靠程度。

📎 拓展(超出 slides) — 一个巧合值得知道:在 ε∼N(0,σ2)\varepsilon \sim N(0,\sigma^2) 且独立的假设下,用 §14 会讲的最大似然估计 (MLE) 去估 β\beta,得到的答案与 OLS 完全相同。所以"OLS 算数值、正态假设做推断"这两件事在数学上是自洽的。

换个角度看:每个 x 处都有一个小钟形曲线

有了这条假设,模型就可以从概率的角度重新解读。Slide 12 写道:对给定的 x1,x2,…,xp−1x_1, x_2, \dots, x_{p-1},

y∼N(β0+β1x1+…+βp−1xp−1,σ2)y \sim N\!\left(\beta_0 + \beta_1 x_1 + \dots + \beta_{p-1}x_{p-1},\ \sigma^2\right)

也就是说,yy 本身是一个随机变量,它服从一个正态分布:均值是线性模型的值,方差是 σ2\sigma^2。所以

E[y∣x]=β0+β1x1+…+βp−1xp−1E[y \mid x] = \beta_0 + \beta_1 x_1 + \dots + \beta_{p-1}x_{p-1}

这正是 slide 的结论:the regression model estimates the expected value of yy for the given value of xx, subject to a normally distributed error term——回归模型估计的是给定 xx 时 yy 的期望值,再叠加一个正态误差。讲师的口语版本是:"The observed Y equals the expected value plus a random noise."

Slide 12 配的图非常形象:一条斜直线,在 x=2,4,6,8,10,12x = 2, 4, 6, 8, 10, 12 处各竖着画了一个"横躺"的钟形曲线,钟形的中心正好落在直线上。讲师:"at each point, there's a small Gaussian distribution... I rotate it in this way." 读这张图要抓住三点:

  • 钟形的中心都在直线上 → 零均值:直线就是每个 xx 处 yy 的平均值;
  • 每个钟形一样宽 → 常数方差:各处的噪声幅度相同;
  • 实际观测点散落在钟形范围内 → 观测值 = 期望值 + 随机扰动。

到这里,§2 那句"线性模型给出期望值"就有了精确的含义。这三条性质也是 §9 诊断要逐一检查的对象——如果实际数据的"钟形"不在直线上、宽窄不一或者根本不是钟形,模型就出了问题。

§6 系数显著吗:对 β 做假设检验

为什么要检验

Slide 16 说明了理由:

  • 系数是 estimated based on the given observed sample only——只根据手上这一份样本估出来的;
  • 所以估计值 有不确定性 (uncertainty);
  • Std. Error 可以用来做假设检验,判断 each coefficient is statistically different from zero(每个系数是否在统计上显著不为零)。

为什么关心"是不是 0"?讲师:"0 means this variable is actually useless because its coefficient is 0." 系数为 0 意味着这个输入对输出没有影响,放在模型里只会增加噪声。讲师强调我们不能把估计值直接当成真值:"We can't simply regard the estimate value as just the same as the ground truth." 比如 Gender 的估计值是 −0.934,不是 0,但它离 0 的这点距离,完全可能只是抽样波动造成的。

检验的步骤

这正是 Week 3 学过的 t 检验,套用到回归系数上:

第 1 步,提出假设(slide 16):

H0:βj=0versusHA:βj≠0H_0: \beta_j = 0 \qquad \text{versus} \qquad H_A: \beta_j \neq 0

零假设 H0H_0 说"这个变量没用",备择假设 HAH_A 说"它有用"。

第 2 步,算 t 统计量:

t=β̂j−0SE(β̂j)t = \frac{\hat\beta_j - 0}{\text{SE}(\hat\beta_j)}

分子是"估计值离 0 有多远",分母是"估计值本身会波动多少"。t 的绝对值越大,说明估计值离 0 的距离远远超出了正常波动范围,越不像是碰巧。

第 3 步,查 p-value:在 H0H_0 成立的前提下,t 服从自由度为 N−pN-p 的 Student's t 分布。由此算出取到比当前 t 值更极端的值的概率,就是 Pr(>|t|) 那一列。

第 4 步,与显著性水平 α\alpha 比较:通常取 α=0.05\alpha = 0.05。

  • p<0.05p < 0.05 → 拒绝 H0H_0 → 系数显著不为 0 → 这个变量有用;
  • p≥0.05p \geq 0.05 → 不能拒绝 H0H_0 → 没有足够证据说它不为 0 → 这个变量可以考虑剔除。

不显著之后怎么办

Slide 17:if a coefficient is NOT statistically different from zero, the coefficient and the associated variable in the model could be excluded——这个系数和对应的变量可以从模型中剔除。

讲师补充了一个容易被忽略的操作要点:剔除之后必须重新拟合。"Once you remove gender, you need to recall this linear model function just based on income, age, and education to regenerate this model, rather than say, oh I remove this one... I still just use this." 不能直接把 Gender 那一项从原方程里划掉、保留其他系数不变——去掉一个变量后,其他系数的估计值也会变化,必须重新调用 lm(Income ~ Age + Education, income_input)。

注意 slide 用的是 could be excluded,不是 must。下一条说明了原因:Better is to combine statistical evidence (p-values) with domain knowledge——统计证据要与领域知识结合。讲师:"because we are dealing with a big data analytic problem, remember, we should always combine the result we obtained from data with our domain knowledge." 比如一项研究的核心问题恰恰是"是否存在性别收入差距",那么即使 Gender 不显著,也应该保留在模型里并报告"未发现显著差异"——这本身就是一个有价值的结论。

"在其他变量都在的条件下"

Slide 16 和 17 各有一句红色批注,点出了一个精妙的地方:

  • Each coefficient's significance is tested conditional on all other predictors being included.(每个系数的显著性,都是在其他所有预测变量都在模型里的条件下检验的。)
  • Does this predictor contribute unique explanatory power, above and beyond what the other predictors already explain?(在其他预测变量已经解释掉的部分之外,这个变量还能贡献独有的解释力吗?)

这意味着 Gender 不显著的准确含义是:在已经知道一个人的年龄和受教育年数之后,再知道他的性别,不能显著改善收入预测。 它不等于"性别与收入毫无关系"。如果性别与教育年数高度相关(比如某个群体受教育普遍更长),那么性别对收入的影响可能已经通过 Education 体现出来了,Gender 单独就显得多余。换一组其他变量,同一个变量的显著性可能完全不同。

📎 拓展(超出 slides) — 两个常见误读:(1)p > 0.05 不等于证明了 βj=0\beta_j = 0,只是"证据不足以拒绝 βj=0\beta_j = 0";样本更大时,一个小的真实效应也可能变得显著。(2)系数大不等于影响大:β\beta 的大小取决于变量的单位。把 Age 的单位从"岁"换成"月",系数会缩小 12 倍,但影响一点没变。本例 Age 与 Education 单位都是"年",才可以直接比较:多一年教育(+1.76)比多一岁(+1.00)对收入的边际作用更大。

系数告诉我们什么

Slide 17 的第一条把这一节收了回来:coefficients provide information on how influential an attribute is on the outcome——系数告诉我们一个属性对输出的影响有多大。讲师的总结是:"The coefficient just indicate how important an attribute is, its relationship with the output value is positive or negative." 读系数要看三样东西:符号(正向还是负向关系)、大小(边际效应多强,注意单位)、显著性(这个效应是否可信)。

§7 R² 与 Adjusted R²:模型解释了多少

Multiple R²

讲师对 Multiple R² 的解释:"It tells us how many percentage of the total variation in income has been explained by the 3 input variables." 本例 R2=0.6364R^2 = 0.6364:收入的总变异中,有 63.64% 能被 Age、Education、Gender 这三个变量解释,剩下 36% 归于模型之外的因素(也就是 ε\varepsilon)。讲师:"the larger the value, the better your model is."

📎 拓展(超出 slides)· R² 的公式 — "总变异"指 yy 围绕其均值的波动,用 total sum of squares SST=∑i(yi−y‾)2\text{SST} = \sum_i (y_i - \bar y)^2 衡量;模型没能解释的部分是残差平方和 SSE=∑i(yi−ŷi)2\text{SSE} = \sum_i (y_i - \hat y_i)^2。于是 R2=1−SSESSTR^2 = 1 - \frac{\text{SSE}}{\text{SST}} 它在 0 到 1 之间。R2=0R^2 = 0 说明模型不比"永远预测平均值"强;R2=1R^2 = 1 说明所有点恰好落在拟合线上。

用 §3 的手算例子:SSE=2.4\text{SSE} = 2.4,SST=(−2)2+02+12+02+12=6\text{SST} = (−2)^2+0^2+1^2+0^2+1^2 = 6,所以 R2=1−2.4/6=0.6R^2 = 1 - 2.4/6 = 0.6——xx 解释了 yy 60% 的变异。

R² 的漏洞:加变量它只升不降

问题在于,只要往模型里加变量,R² 就不会下降,哪怕加的是完全无关的变量。讲师:"By simply increasing the number of input variables, even you introduce irrelevant variables, you can actually increase the multiple R². This causes problem — the potential overfitting problem."

为什么?因为 OLS 总可以把新变量的系数设为 0,退回原来的模型;所以加了新变量之后 SSE 只会持平或下降,R² 只会持平或上升。一个随机生成的噪声列,也会碰巧和 yy 有一点点相关,OLS 就会利用这点巧合把 SSE 压低一点点。

这与上周讲的 overfitting 是同一回事:讲师把它联系起来——"Overfitting means if you keep adding features, you may keep reducing the training error, but actually the generalization capability could decrease." 只看 R² 选模型,会诱导你不停地加变量。

Adjusted R²:给变量个数加惩罚

Adjusted R² 修正了这个漏洞。讲师:"When we calculate the R², we also consider the number of input variables you use... can you use a small number of input features as possible to explain the total variance of the output." 它同时考虑两样东西:模型解释了多少变异,以及模型有多复杂。

📎 拓展(超出 slides)· Adjusted R² 的公式与验算 — 设样本数为 NN,输入变量个数为 kk(即 p−1p-1): Radj2=1−(1−R2)N−1N−k−1R^2_{\text{adj}} = 1 - (1 - R^2)\,\frac{N-1}{N-k-1} 分式 N−1N−k−1\frac{N-1}{N-k-1} 总是大于 1,而且 kk 越大它越大——这就是对变量个数的惩罚。

加入一个新变量时,R² 一定会升一点,惩罚也一定会加重一点。如果新变量带来的解释力不足以抵消惩罚,Adjusted R² 就会下降。 这正是 slide 24 那条警告的意思(slide 上 "Adjusted" 一词是手写插进去的):Be careful when adding more variables — the Adjusted R² value may decrease because of the increased input dimension.

§8 类别变量:m 个取值,用 m−1 个 binary 变量

问题

到目前为止,输入都是数:年龄、受教育年数。可现实数据里大量变量是类别型 (categorical) 的。Slide 18 举了 gender、ZIP codes(邮编)、nationality(国籍),讲师又加了星期几、月份。它们的取值是标签,不是数量,线性方程却只能处理数。怎么把它们放进 βjxj\beta_j x_j?

错误做法:按字母顺序编号

Slide 18 明确指出:An incorrect approach is to assign a number to each of them based on an alphabetical ordering——按字母顺序给每个类别分配一个数字,是错误的。

比如国籍按字母排序编号:Australia = 1,China = 2,India = 3。模型里只有一项 β⋅Nationality\beta \cdot \text{Nationality},于是它会认为:

  • 国籍之间存在顺序:India > China > Australia;
  • 而且间距相等:India 与 China 的差异,恰好等于 China 与 Australia 的差异;
  • 所有国籍对 yy 的影响,必须落在同一条直线上。

这些都是编号凭空制造出来的。讲师:"If you put 1, 2, 3, 4, 5 to represent the category variable, you introduce something unnecessary — its ordering." 换一种编号方式,模型的结论就会变,这显然荒谬。

正确做法:m − 1 个 binary 变量

Slide 18:For a categorical variable that can take mm different values, we shall add m−1m-1 binary variables to the regression model.

讲师用颜色举例:一个颜色变量有 Red、Green、Blue 三个取值(m=3m = 3),就加 3−1=23 - 1 = 2 个 0/1 变量。选一个类别当基准 (baseline),比如 Red,它不需要自己的变量:

颜色 xGreenx_{\text{Green}} xBluex_{\text{Blue}}
Red(基准) 0 0
Green 1 0
Blue 0 1

模型变为 y=β0+βGxGreen+βBxBlue+…y = \beta_0 + \beta_G x_{\text{Green}} + \beta_B x_{\text{Blue}} + \dots,于是:

  • Red 的预测值:β0+…\beta_0 + \dots
  • Green 的预测值:β0+βG+…\beta_0 + \beta_G + \dots
  • Blue 的预测值:β0+βB+…\beta_0 + \beta_B + \dots

所以 βG\beta_G 的含义是"Green 相对于基准 Red 的差异",βB\beta_B 同理。三个类别各自拥有独立的效应,不再有虚构的顺序和间距。这种 0/1 变量通常叫 dummy variable(哑变量)。这种编码相当于 one-hot encoding 去掉基准类别那一列。

收入模型里的 Gender 正是这样处理的:两个取值,m−1=1m - 1 = 1 个 0/1 变量。Gender 的系数 −0.934 就是"Gender = 1 相对于 Gender = 0"的差异。

为什么是 m − 1,不是 m

讲师专门解释了这个问题。如果模型有截距 β0\beta_0,却给 RGB 加了全部 3 个 dummy:

颜色 截距列 xRx_R xGx_G xBx_B xR+xG+xBx_R + x_G + x_B
Red 1 1 0 0 1
Green 1 0 1 0 1
Blue 1 0 0 1 1

每一行恰好有一个 1,所以三个 dummy 列加起来永远等于 1——与截距那一列一模一样。讲师:"Each time there's one and only one 1... And also in a matrix form, the column corresponding to the intercept will also be one... This causes the collinearity between the intercept column and the sum of the coefficient... you will find actually that there are infinite number of solutions."

为什么会有无穷多个解?假设 (β0,βR,βG,βB)(\beta_0, \beta_R, \beta_G, \beta_B) 是一组解。把截距加上任意常数 cc,三个 dummy 系数都减去 cc,得到 (β0+c,βR−c,βG−c,βB−c)(\beta_0 + c,\ \beta_R - c,\ \beta_G - c,\ \beta_B - c)。对任何一行,预测值变化了 +c−c=0+c - c = 0,完全不变。cc 可以取任何值,所以 OLS 找不到唯一的最优解——用 §3 拓展框的话说,X⊤XX^\top X 不可逆。

📎 拓展(超出 slides) — 这个陷阱有个专门的名字:dummy variable trap(哑变量陷阱)。它是 §19 multicollinearity(多重共线性) 的一个极端特例:某几列之间存在精确的线性关系。

讲师也给了反面情况:"if you say I don't want to use the intercept, I don't have beta zero, then you can use mm binary variables." 没有截距列,就不存在"加起来等于截距列"的冲突,mm 个 dummy 可以全用,每个系数直接表示该类别自己的水平。

一句话记住:有截距用 m−1m-1 个,无截距可用 mm 个。实践中模型几乎总带截距,所以默认是 m−1m-1。

📎 拓展(超出 slides) — 在 R 里,只要把类别变量存成 factor 类型,lm() 会自动生成 m−1m-1 个 dummy,并把字母序第一个水平当作基准。Python 的 pandas.get_dummies(..., drop_first=True) 做同样的事。

§9 模型诊断:假设真的成立吗

为什么要诊断

到这里我们已经能拟合模型、读输出、检验系数了。但 §6 的 t 值、p 值和 §7 的 R² 都建立在 §4 的那组假设之上。讲师:"All the hypothesis tests is based on this assumption. So that means after we obtain our model, we need to go back to check whether this assumption is well satisfied. If not, we need to go back to modify our model."

Slide 19:linear regression models depend on assumptions,所以我们必须 validate a fitted regression model(验证拟合好的模型),具体分三项:

  1. Evaluate the linearity assumption —— 线性假设
  2. Evaluate the residuals —— 残差(零均值、常数方差)
  3. Evaluate the normality assumption —— 正态性

9.1 线性假设

怎么查:Slide 20——plot the outcome variable against each input variable,把输出对每个输入分别画散点图。

Slide 20 配的图是 Income 对 Age 的散点图,呈现一个倒 U 形:20 岁到 45 岁左右收入随年龄上升,之后随年龄下降。讲师:"You find that actually the age and income is not linear." 这在现实中说得通:职业生涯前半段收入增长,临近退休开始回落。用一条直线去拟合一道拱形,怎么摆都不对。

怎么修:Slide 20 给了两条路——

  • Transform the outcome or input variables:变换输出或输入,比如取对数、开平方;
  • Add extra input variables:加入新的输入变量,比如 age squared(Age2\text{Age}^2)。

倒 U 形正是二次函数的形状。讲师:"since we have seen the second-order relationship, maybe you need to use age square." 新模型是:

Income=β0+β1Age+β2Education+β3Gender+β4Age2+ε\text{Income} = \beta_0 + \beta_1\,\text{Age} + \beta_2\,\text{Education} + \beta_3\,\text{Gender} + \beta_4\,\text{Age}^2 + \varepsilon

β4\beta_4 估出来会是负数,让曲线在高龄段弯下来。

"线性"到底指什么

现在可以揭开 §2 留下的那个括号了。新模型里有 Age2\text{Age}^2,Income 与 Age 显然不是线性关系。那它还算线性回归吗?

算。 讲师正是用这个例子说明的:"Clearly, the relationship between the input variable and the Y is not linear. We have to add new features. But why we can still use linear regression? ... the linear regression is essentially between the output Y and these betas. Mathematically, the linear means the linear relationship between output Y and beta 1, beta 2, beta 3, beta 4."

Slide 4 底部的注释说得最准确:The "linear" in linear regression refers to the linear relationship between the output and a set of features, which may be raw input variables or transformations of them. "线性"指的是 yy 与参数 β\beta 之间是线性的——yy 是若干特征的加权和,权重就是 β\beta。至于这些特征是原始变量 Age,还是变换后的 Age2\text{Age}^2、log(Age)\log(\text{Age}),都无所谓。从 OLS 的角度看,Age2\text{Age}^2 不过是数据表里新加的一列数,求解方法完全不变。

判断方法:把每个 β\beta 都看成未知数,方程是不是这些未知数的一次式?

模型 对 β\beta 线性? 说明
y=β0+β1x+β2x2+εy = \beta_0 + \beta_1 x + \beta_2 x^2 + \varepsilon ✅ x2x^2 只是一个新特征
y=β0+β1logx+εy = \beta_0 + \beta_1 \log x + \varepsilon ✅ 变换输入
logy=β0+β1x+ε\log y = \beta_0 + \beta_1 x + \varepsilon ✅ 变换输出
y=β0+β1x1+β2x1x2+εy = \beta_0 + \beta_1 x_1 + \beta_2 x_1 x_2 + \varepsilon ✅ 交叉项也只是新特征
y=β0+eβ1x+εy = \beta_0 + e^{\beta_1 x} + \varepsilon ❌ β1\beta_1 在指数上
y=β0+xβ1+εy = \beta_0 + x^{\beta_1} + \varepsilon ❌ β1\beta_1 是幂次
y=β01+β1x+εy = \dfrac{\beta_0}{1 + \beta_1 x} + \varepsilon ❌ β1\beta_1 在分母里

这个认识让线性回归的适用面大大扩展:只要能通过变换把关系"拉直",就能用线性回归。 §20 会回到这一点。

9.2 残差:零均值与常数方差

残差的定义在 slide 21 再次给出:Residual = Observed − Predicted。

为什么查残差?§4 假设 ε∼N(0,σ2)\varepsilon \sim N(0, \sigma^2) 且相互独立,而残差就是我们对 ε\varepsilon 的观测。Slide 21:If this assumption is violated, the various inferences are suspect——假设一旦被违背,各种推断(标准误、t 值、p 值)都不可信了。

怎么查:画 residuals vs fitted values 图——横轴是预测值 ŷ\hat y,纵轴是残差。

好的残差图(slide 21):点在 0 这条水平线上下均匀散开,形成一条宽度不变的水平带,看不出任何规律。讲师:"whether the mean of the residue corresponding to different y value is roughly zero — yeah it is. And also whether the fluctuation of the residue is symmetrical with respect to the zero mean, and also it's constant." 对应的结论写在图下:Residuals have zero mean and a constant variance.

这与 §4 的钟形曲线图是同一件事的两面:钟形中心都在直线上 → 残差围绕 0;钟形宽度相同 → 残差带宽度不变。

有问题的残差图(slide 22,"How about these residual plots?")给了四种反例。讲师的结论是:"For any one of them, we have to say no. The assumption is violated. We need to go back to redesign our model."

最后一项:残差是否服从正态分布?Slide 23 给了两个选项。

Option 2:Q-Q plot。R 代码:

qqnorm(results2$residuals, ylab="Residuals", main="")

(results2 是另一个已拟合的模型对象,slides 没有交代它的来源,从上下文看很可能是加入 Age2\text{Age}^2 之后的模型。)

  • 点几乎都落在直线上 → 残差服从正态分布(slide 23 右上图,标 Normality distributed);

📎 拓展(超出 slides)· Q-Q plot 在画什么 — Q-Q 是 quantile–quantile 的缩写。做法是:把 NN 个残差从小到大排序;再算出"如果数据来自标准正态分布,第 1 小、第 2 小……第 NN 小的值理论上应该是多少"(theoretical quantiles,即横轴)。以理论值为横坐标、实际残差为纵坐标作图。如果残差真的服从正态分布,实际值与理论值成正比,点就排成一条直线。两端翘起说明尾部比正态分布更"厚"(极端值更多),一端弯曲说明分布偏斜。

§10 其他注意事项

Slide 24 列出了几条零散但实用的建议。

1. 尽早考虑所有可能的输入变量(Consider all possible input variables early in the analytic process)。讲师把它放回了 Week 2 的生命周期:"In the big data analytic life cycle, we need to consider all possible input variables early. Don't simply remove the input variable. Check the relationship between the input variable and the output variable." 在 discovery 和 model planning 阶段就把候选变量列全,逐个看它们与输出的关系,而不是建完模型才想起漏了什么。

2. 加变量要谨慎(Be careful when adding more variables)。这与第 1 条并不矛盾:考虑要全,放进模型要挑。理由就是 §7 的 Adjusted R²——无用的变量会让它下降,也会引发 overfitting。

3. 线性回归对离群点敏感(Linear regression is sensitive to outliers)。Outlier(离群点) 是指 observed points that are markedly different from the majority of the points——与大多数点明显不同的观测。原因在 §3 的拓展框里已经说过:OLS 最小化的是平方误差,一个偏离 50 的点贡献 2500,足以把整条直线拽向它。Slide 要求 examine any outliers——先用可视化(散点图、残差图)找出来,再判断。讲师说找到后 "you need to remove it";更稳妥的做法是先查原因:如果是录入错误或者不属于研究对象(比如收入数据里混进了一个亿万富翁),可以删除;如果是真实且有代表性的数据,删掉它反而会让模型脱离现实。

4. 检查系数的大小和符号是否合理(Examine if the magnitudes and signs of the estimated parameters make sense)。讲师:"Incorporate the domain knowledge to examine whether the magnitude and the sign of the beta value makes sense. If you see the beta value is negative, it indicates the relationship between Y and this input variable is negative... whether this is consistent with your domain knowledge you have collected in the stage one of life cycle." 比如收入模型里 Education 的系数如果是负的——受教育越多收入越低——就与常识相悖,很可能是数据或模型出了问题(变量编码错误、遗漏了关键变量、存在多重共线性等),而不是发现了什么惊人的规律。

Part III · Logistic Regression

§11 当输出是类别:为什么需要 logistic regression

从连续值到概率

Slide 25 的开头很简单:In linear regression, the outcome variable is a continuous variable. When the outcome variable is categorical in nature, logistic regression can be used — to predict the probability of an outcome based on the input variables.

线性回归输出一个连续值;logistic regression(逻辑回归) 输出一个概率——讲师:"probability of positive, probability of negative, probability of subscribed, probability of not subscribed." 有了概率,再按一个阈值转成类别标签,就完成了分类。

讲师把它和上周的 naïve Bayes 放在一起看:"It's very similar to naive Bayes classifier. Naive Bayes classifier also predicts the probability corresponding to the class labels." 两者都是概率型分类器,先给出每个类别的概率,再做决定。区别在于概率怎么算:naïve Bayes 用 Bayes' theorem 加条件独立假设,logistic regression 用一个线性函数加一层变换。

📎 拓展(超出 slides)· 为什么不直接拿线性回归预测 0/1? — 一个自然的想法是:把"流失"编码为 1、"未流失"编码为 0,直接跑线性回归,把输出当概率。问题在于直线是无界的:对一个很年轻、身边很多人已流失的客户,直线可能预测出 1.3;对一个年长、身边没人流失的客户,可能预测出 −0.4。概率不可能大于 1 或小于 0。另外,yy 只取 0 和 1,残差也不可能服从 §4 要求的正态分布。我们需要一个输出永远落在 0 和 1 之间的模型——这就是下一节 logistic function 的用处。

用例

Slide 26 列了四个领域,每一个的输出都是"某事件发生的概率":

为什么一个分类方法叫"回归"?讲师:"Because it is a combination of logistic function and the linear regression. That's why it's called logistic regression. It just combined the two names." 它确实包含一个线性回归,只是外面套了一层 logistic function。接下来两节分别拆开这两部分。

§12 Logistic function:把任意实数压进 (0, 1)

Slide 27 给出了 logistic function:

f(y)=ey1+ey,−∞<y<∞f(y) = \frac{e^y}{1 + e^y}, \qquad -\infty < y < \infty

它的作用,讲师说得很透:"The logistic function can map any number between minus infinity and positive infinity to a value between 0 and 1. You may ask why we need this? Remember, logistic regression is to predict probability... Probability is a value between 0 and 1. And also logistic regression uses linear regression. The output of linear regression is a continuous value [that] can stay anywhere between minus infinity and positive infinity. So, to bridge the output of linear regression and a probability, we need the logistic function."

一句话:线性回归的输出范围是 (−∞,∞)(-\infty, \infty),概率的范围是 (0,1)(0, 1),logistic function 是连接两者的桥。

§13 两层结构:线性回归,外面套一层 logistic

第一层:一个看不见的线性回归

Slide 28:In logistic regression, yy is expressed as a linear function of the input variables——

y=β0+β1x1+β2x2+…+βp−1xp−1y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_{p-1} x_{p-1}

与线性回归的方程一模一样(这里不写 ε\varepsilon,因为随机性在下一层体现)。但 slide 用蓝字加了一句关键的话:but yy is not observed! Only f(y)f(y) is observed!

这句话怎么理解?讲师解释:"In logistic regression, your training data — the input variables same. But the output... is a class label. We are dealing with classification... In linear regression, the Y is really the output variable, but in logistic regression we don't have Y, we just have class label. So that's why we say Y is not observed."

在收入例子里,训练数据的每一行都写着实际收入 yy;而在流失例子里,每一行只写着"流失了 / 没流失",没有任何一列叫 yy。yy 是模型内部的一个中间量,我们看到的只有它经过变换、再"掷一次骰子"之后的结果:类别标签。

📎 拓展(超出 slides) — 更精确地说,我们观测到的也不是 f(y)f(y) 这个概率本身(训练数据里没有一列写着"流失概率 0.73"),而是按这个概率随机产生的 0/1 结果。Slide 的意思是:与线性回归不同,yy 不再是数据里现成的一列。

第二层:把 y 变成概率

Slide 28 接着写出事件 CC(比如"流失")发生的概率:

P(C∣x1,x2,…,xp−1)=f(y)=ey1+eyP(C \mid x_1, x_2, \dots, x_{p-1}) = f(y) = \frac{e^y}{1+e^y}

把第一层的 yy 代进去,就是 logistic regression 的完整形式:

P=eβ0+β1x1+β2x2+…+βp−1xp−11+eβ0+β1x1+β2x2+…+βp−1xp−1P = \frac{e^{\beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_{p-1}x_{p-1}}}{1 + e^{\beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_{p-1}x_{p-1}}}

讲师劝大家别被这个式子吓到:"Don't be afraid by this formula. Essentially it's just I replace the Y with a linear regression. So you can see that actually there are two layers in logistic regression. One layer is just a normal linear regression. On top of it, we put a logistic function to convert it to a probability value. That's all. Essentially it is a linear regression inside, [and] you have a cover."

前两层是 slide 28 的内容;最后的阈值判断是 §16 的内容。

Slide 29 把上式反解出 yy:

左边这个量叫 PP 的 logit,slide 称之为 log odds ratio。讲师:"Here you see, I represent P by Y. Now I represent Y by P. They are the same, you can derive this... It's not difficult."

📎 拓展(超出 slides)· 推导 — 从 P=ey1+eyP = \dfrac{e^y}{1+e^y} 出发:两边乘以 1+ey1 + e^y 得 P+Pey=eyP + Pe^y = e^y;移项得 P=ey(1−P)P = e^y(1-P);所以 ey=P1−Pe^y = \dfrac{P}{1-P};两边取自然对数,y=lnP1−Py = \ln\dfrac{P}{1-P}。

📎 拓展(超出 slides)· odds 是什么 — P1−P\dfrac{P}{1-P} 叫 odds(几率、赔率):事件发生的概率与不发生的概率之比。赌球时说"4 赔 1",就是这个意思。

三个尺度的范围依次是:概率 (0,1)(0,1),odds (0,∞)(0,\infty),log odds (−∞,∞)(-\infty,\infty)。每取一步,范围就"打开"一点,到 log odds 时与线性函数的范围完全对上。所以 logistic regression 的本质是:用线性回归去建模 log odds。 这句话就是 slide 29 那个等式的含义。

注意 slide 用的词是 "log odds ratio"——这里的 ratio 指 PP 与 1−P1-P 之比本身,即 odds。§15 会出现另一个概念 odds ratio(两个 odds 之比),不要混淆。

§14 怎么求 β:Maximum Likelihood Estimation

为什么不能用 OLS

线性回归用 OLS 求 β\beta:最小化观测值 yiy_i 与预测值之差的平方和。可在 logistic regression 里,yy 根本没被观测到(§13),"yiy_i 减预测值"无从算起。讲师:"We don't use the OLS anymore... In linear regression we use OLS, but here in logistic regression we don't use OLS, we use something called maximum likelihood estimation."

MLE 的思路

Slide 29:Maximum Likelihood Estimation (MLE) is often used to estimate the model parameters. It finds the parameter values that maximize the chances of observing the given dataset——它寻找使"观测到手上这份数据"的可能性最大的参数值。

讲师说这是统计模式识别里 "a widely used principle to estimate parameters",高层的想法是:"The likelihood is what we have observed. So we need to set the value of the beta to support the likelihood of what we have observed." 数据已经发生了,哪组参数最能"解释"它为什么会这样发生,就选哪组。

§16 从概率到类别:阈值

Slide 31:Logistic regression is often used as a classifier to assign class labels to a data example, based on the predicted probability. 有了概率,还要定一个阈值 (threshold):概率高于阈值判为正类,否则判为负类。

Commonly, 0.5 is used as the default probability threshold. 讲师:"If the predicted probability is over 0.5, you say yes or positive. Lower than 0.5, you say no or negative."(录音转写成了 "1.5",是 0.5 的误识别。)

§17 ROC 曲线与 AUC

复习:四个格子

Slide 32 标题是 Diagnosis (review),复习了上周的 confusion matrix。设正类为 CC,负类为 ¬C\neg C:

实际为 CC 实际为 ¬C\neg C
预测为 CC TP(true positive):预测 CC,实际 CC FP(false positive):预测 CC,实际 ¬C\neg C
预测为 ¬C\neg C FN(false negative):预测 ¬C\neg C,实际 CC TN(true negative):预测 ¬C\neg C,实际 ¬C\neg C

一个好记的办法:第二个字母(P/N)是模型的预测,第一个字母(T/F)是预测对不对。FP 就是"预测成 Positive,但预测错了(False)"。

由此定义三个指标("#"表示"个数"):

Accuracy=TP+TNTP+FP+TN+FN\text{Accuracy} = \frac{TP + TN}{TP + FP + TN + FN}

FPR=FPFP+TNTPR=TPTP+FN\text{FPR} = \frac{FP}{FP + TN} \qquad\qquad \text{TPR} = \frac{TP}{TP + FN}

  • TPR(true positive rate,真正率):实际为正的样本里,被正确找出来的比例。也叫 recall 或 sensitivity。
  • FPR(false positive rate,假正率):实际为负的样本里,被误报成正的比例。

⚠️ Slide 32 的两个分母写错了,考试按上面的写法 — Slide 上写的是 FPR=#FP#TN+#FN\text{FPR} = \frac{\#FP}{\#TN + \#FN} 和 TPR=#TP#TP+#FP\text{TPR} = \frac{\#TP}{\#TP + \#FP}。前者的分母混进了 FN(那是实际为正的样本);后者其实是 precision 的公式。正确的分母都是"实际属于某一类的样本总数":TPR 的分母是全部实际正类 TP+FNTP + FN,FPR 的分母是全部实际负类 FP+TNFP + TN。这与 Week 5 讲义 §42 一致。

ROC 曲线是什么

Slide 33:Receiver Operating Characteristic (ROC) curve is the plot of the True Positive Rate (TPR) against the False Positive Rate (FPR)——以 FPR 为横轴、TPR 为纵轴画出的曲线。

讲师顺带讲了名字的来历:"I think it was used in 1940s, used for radar to detect any unknown flying object." 这个名字来自二战时的雷达信号检测:"receiver"是雷达接收机,操作员要在噪声中分辨敌机信号,灵敏度调高会多报假目标,调低会漏掉真敌机——与 §16 的阈值取舍完全是同一个问题。

A classifier shall have a low FPR and a high TPR——好的分类器误报少、命中多。讲师:"We want to minimize the false positive rate. We don't like false positive... We hope the true positive rate to be as high as possible." 所以 ROC 图上最理想的点是左上角 (0,1)(0, 1):FPR = 0、TPR = 1,一个不漏、一个不错。

曲线是怎么画出来的

一个固定阈值只能得到一个 confusion matrix,也就只能得到一个点 (FPR, TPR)。讲师:"When you adjust the probability threshold, use different probability thresholds from 0, 0.1, 0.2, ... until 0.9, until 1.0. You use each of them as your threshold to do classification. You usually get a line like this." 让阈值从高到低扫一遍,每个阈值算一个点,连起来就是 ROC 曲线。

两个端点总是固定的:

  • 阈值高于所有概率:谁都不判为正类,TP = FP = 0 → 点 (0,0)(0, 0);
  • 阈值为 0:所有样本都判为正类,FN = TN = 0 → 点 (1,1)(1, 1)。

Slide 33 的最后一条:A metric: the area under the ROC curve (AUC)。曲线越靠近左上角,曲线下的面积越大。讲师:"If the value is high, closer to 1.0, means your classifier has a good performance." Slide 上的示例曲线 AUC = 0.8877。

📎 拓展(超出 slides)· AUC 的概率含义 — AUC 等于:随机抽一个正样本和一个负样本,模型给正样本的概率高于负样本的概率的可能性。 用上面的例子验证:4 个正类 × 5 个负类 = 20 对。客户 9(0.930)与客户 8(0.808)的概率高于全部 5 个负类;客户 7(0.664)和客户 5(0.460)各高于 4 个负类(都低于客户 6 的 0.727)。合计 5+5+4+4=185+5+4+4 = 18,18/20=0.918/20 = 0.9,与面积算出的结果一致。这也解释了为什么随机猜的 AUC 是 0.5:正负样本谁高谁低全凭运气,各占一半。

Part IV · 选型与警示

§18 线性还是 logistic:按输出类型选

Slide 34 给出了选择依据:

  • Linear regression:input variables 可以是 continuous or discrete(连续或离散),outcome variable 是 continuous;
  • Logistic regression:outcome variable 是 categorical 时更好的选择;
  • Both models assume a linear additive function of the input variables——两者都假设输入变量以线性相加的方式起作用。

最后一条值得多想一下。"additive(可加)"意味着每个变量的作用各自独立地加进来:Age 的效应不会因为 Education 的取值而改变。如果现实中"教育的回报随年龄增长而变大",这种交互作用就不在模型里,除非你手动加一个 Age×Education\text{Age} \times \text{Education} 的交叉项(§20)。对 logistic regression 来说,线性可加还意味着它的分类边界是一条直线(§16 拓展框)。

讲师把选择范围放得更宽:输出是类别时,上周和本周学过的分类器都可以用;输出是连续值时,线性回归是首选,但不是唯一选择。"If you find the outcome is categorical, you can choose decision tree, naive Bayes classifier, logistic regression, or neural networks... If your outcome variable is continuous, the first you should consider linear regression. You can also use decision tree because decision tree can also handle continuous [outcome]... or neural networks."

📎 拓展(超出 slides) — slide 2 的大纲里有一项 "Additional Regression Models",本周 slides 对此只在 slide 35 提到了 Ridge 与 Lasso(见 §19)。讲师口头提到的 decision tree 用于回归,通常叫 regression tree:叶节点存放的不是类别,而是落入该叶节点的样本输出的平均值。

§19 三条警示

Slide 35 列出了使用回归时必须记住的三件事。

警示一:相关不等于因果

Correlation does not imply causation. We shall NOT infer that the input variables directly cause an outcome.

讲师:"So far we discussed the relationship between Y and X. We just talked about the correlation. Correlation means they increase together or decrease together, or one increases, one decreases. It's just correlation. Correlation does not imply causation."

回归能告诉我们"受教育年数多的人,收入往往更高"(Education 系数为正且显著),但不能告诉我们"让一个人多读一年书,他的收入就会涨 1.76"。可能存在第三个因素同时影响两者——比如家庭背景:家境好的人既更可能读更多书,也更可能拿到高薪。

📎 拓展(超出 slides) — 经典的反例:冰淇淋销量与溺水人数高度相关,拿一个去回归另一个会得到显著的正系数。但禁售冰淇淋不会减少溺水,两者都是被"天气炎热"这个共同原因推高的。这种共同原因叫 confounder(混杂变量)。讲师说 "in order to infer causality, we need another set of algorithms, not linear regression",指的是随机对照实验、因果推断方法等。

警示二:不要在训练数据范围外使用模型

Generalization issue — use caution when applying an already fitted model to data that falls outside the dataset used to train the model.

讲师:"You should apply your model only to the range that is covered by your training data. If your training data is collected from a range from A to B, then your linear model will generally work well within the range of A to B... If you want to apply the model to a new range, you need to collect the data to cover the range outside of the original dataset."

收入模型的训练数据,年龄大致在 20 到 70 岁之间(见 §9 的散点图)。用它预测一个 10 岁孩子或 95 岁老人的收入,结果毫无意义。§5 提到截距 7.263("0 岁、0 年教育"时的收入)没有现实含义,原因正在于此。加了 Age2\text{Age}^2 之后问题更突出:二次曲线在 70 岁之后会一路向下,外推到 100 岁可能预测出负收入。

📎 拓展(超出 slides) — 在训练数据范围之外做预测叫 extrapolation(外推);在范围之内叫 interpolation(内插)。模型在训练范围内学到的关系,到了范围外不一定还成立。

警示三:多重共线性

Multicollinearity issue — Ridge regression and Lasso regression.

Multicollinearity(多重共线性) 指输入变量之间高度相关。讲师:"You need to pay particular attention to whether the features are strongly correlated. If two features are strongly correlated, it will cause multicollinearity issue... you will not get a good solution or single solution. In principle, there will be an infinite number of solutions because your system becomes an underdetermined system."

这里要分两种程度:

  • 完全共线:某个变量能被其他变量精确地线性表示。比如同时放入"面积(平方米)"和"面积(平方英尺)",后者恰好是前者的 10.76 倍;或者 §8 的哑变量陷阱。这时 X⊤XX^\top X 不可逆,OLS 有无穷多个解——讲师说的就是这种情况。
  • 高度相关但不完全共线:比如"居住面积"和"卧室数量"。这时解是唯一的,但极不稳定:标准误被放大、p 值变大,数据稍有变化,系数就大幅摆动,甚至符号翻转。两个变量"抢着"解释同一部分变异,模型分不清功劳归谁。这也是 §10 第 4 条"系数符号不合常识"的常见原因。

解决办法,slide 给出了 Ridge regression 和 Lasso regression,讲师称之为 regularization(正则化)。

📎 拓展(超出 slides)· Ridge 与 Lasso — 两者都在 OLS 的目标函数后面加一个惩罚项,不让系数变得太大:

目标函数 效果
OLS min∑i(yi−ŷi)2\min \sum_i (y_i - \hat y_i)^2 —
Ridge min∑i(yi−ŷi)2+λ∑jβj2\min \sum_i (y_i - \hat y_i)^2 + \lambda \sum_j \beta_j^2 把系数整体往 0 收缩,让解唯一且稳定
Lasso min∑i(yi−ŷi)2+λ∑j|βj|\min \sum_i (y_i - \hat y_i)^2 + \lambda \sum_j \lvert\beta_j\rvert 能把部分系数压到恰好为 0,顺带做变量选择

λ≥0\lambda \geq 0 控制惩罚的力度,是一个超参数,可以用上周讲的 cross-validation 来选。更简单的办法是直接从一组高度相关的变量里只保留一个。

§20 总结:变换变量,是线性回归的日常

Slide 36 的总结:

  • Linear regression and logistic regression model observed data to predict future outcomes——两者都是用观测数据建模来预测未来;
  • Care must be taken in performing and interpreting a regression analysis——做回归和解读回归都需要小心:
    • Determine the best input variables and their relationship to outcome variables(§6、§7、§10)
    • Understand and validate underlying assumptions(§4、§9)
    • Transform variables when necessary(§9、本节)

讲师在课末把重点放在了最后一条上,值得完整转述:"For linear regression, it does not mean, OK, I was given this input variable, I have this output variable, I just train a linear model use this input variable. No. Usually you need to consider adding more attributes by transforming the original attributes to multiple different versions to enrich my model, because, common case, the relationship between the outcome variable and the raw input variable are not linear."

拿到数据直接把原始变量塞进 lm(),通常不够。关系常常不是线性的,需要先变换,把它"拉直"。讲师列举的变换有:

变换 对象 典型用途
log(取对数) 输出或输入 右偏、跨度大的量(收入、房价);缓解喇叭形残差
square root(开平方) 输出或输入 计数类数据;较温和的压缩
square(平方) 输入 倒 U 形或 U 形关系(Age²)
cross term(交叉项,两两相乘) 输入对 一个变量的作用随另一个变量而变(交互作用)

讲师称交叉项和平方项为 "second-order information"(二阶信息)。这些变换都不破坏"对系数线性"(§9),所以变换后仍然用 OLS 求解。他也强调 "you don't need to do this by yourself... you just need to indicate, OK, I want to take this transformation, I want to consider the cross term. The function will do this automatically for you."

📎 拓展(超出 slides) — 在 R 的公式里,这些变换可以直接写:

lm(log(Income) ~ Age + I(Age^2) + Education + Age:Education, data = income_input)

log(Income) 变换输出;I(Age^2) 加平方项(I() 告诉 R 按算术理解 ^);Age:Education 加交叉项。

本章小结 (Key takeaways)

  1. Regression 预测连续数量,classification 预测离散类别,这是两者唯一的区别;logistic regression 名叫回归,实际用于分类,因为它的内核是一个线性回归,外面套了一层 logistic function。

  2. 线性回归模型是 y=β0+β1x1+…+βp−1xp−1+εy = \beta_0 + \beta_1x_1 + \dots + \beta_{p-1}x_{p-1} + \varepsilon:β0\beta_0 是所有输入为 0 时的 yy,βj\beta_j 是其他输入不变时 xjx_j 每增加 1 个单位 yy 的变化,ε\varepsilon 是线性模型与实际观测之间的随机误差。

  3. OLS 通过最小化残差平方和 ∑i(yi−ŷi)2\sum_i(y_i - \hat y_i)^2 求 β\beta;平方是为了避免正负抵消,也让问题有闭式解,代价是对离群点敏感。

  4. OLS 本身不对误差做假设;常用的 linear regression model 额外假设 ε∼N(0,σ2)\varepsilon \sim N(0,\sigma^2) 且相互独立。β\beta 的数值仍由 OLS 算出,这条假设换来的是统计推断能力(标准误、t 值、p 值),并让模型可以解读为"估计给定 xx 时 yy 的期望值"。

  5. 读 summary(lm(...)):Estimate 是系数,Std. Error 是它的抽样波动,t=Estimate/SEt = \text{Estimate}/\text{SE},Pr(>|t|) 是检验 H0:βj=0H_0: \beta_j = 0 的 p 值;在 α=0.05\alpha = 0.05 下 p<0.05p < 0.05(至少一颗星)才算显著。收入例子中 Gender 的 p=0.134p = 0.134,不显著,可以剔除——剔除后要重新拟合,并结合领域知识决定。显著性是在其他变量都在模型中的条件下检验的。

  6. Multiple R² 是模型解释的变异比例,加变量只升不降;Adjusted R² 对变量个数施加惩罚,加入贡献不足的变量会让它下降,比较不同规模的模型时应看 Adjusted R²。

  7. 有 mm 个取值的类别变量用 m−1m-1 个 binary 变量编码;按字母顺序编号会凭空制造顺序与等间距;有截距时用 mm 个会让 dummy 列之和等于截距列,导致无穷多解(哑变量陷阱)。

  8. "Linear" 指 yy 对系数 β\beta 线性,特征可以是原始变量的变换(Age2\text{Age}^2、logx\log x、交叉项);所以非线性关系常常可以通过变换后仍用线性回归处理。

  9. 模型诊断三项:outcome 对每个 input 作图检查线性;residuals vs fitted 图检查零均值与常数方差(拱形、斜带、偏移、喇叭形都是违背);直方图或 Q-Q plot(qqnorm + qqline)检查正态性。不通过就变换变量或加变量后重新拟合。

  10. Logistic function f(y)=ey1+eyf(y) = \frac{e^y}{1+e^y} 把 (−∞,∞)(-\infty,\infty) 映射到 (0,1)(0,1);logistic regression 用线性函数建模 log odds:lnP1−P=β0+∑jβjxj\ln\frac{P}{1-P} = \beta_0 + \sum_j\beta_jx_j。由于 yy 观测不到,参数改用 MLE(使观测到这份数据的可能性最大)而非 OLS 求得。

  11. Logistic regression 用阈值把概率转成类别,默认 0.5;提高阈值减少 FP、增加 FN,降低阈值则相反。ROC 曲线扫遍所有阈值,画出 TPR 对 FPR,理想点在左上角 (0,1)(0,1);AUC 越接近 1 越好,0.5 等于随机猜。

  12. 三条警示:相关不等于因果;不要把模型用在训练数据范围之外;输入变量高度相关(multicollinearity)会让系数不稳定甚至无唯一解,可用 Ridge / Lasso 正则化缓解。

参考答案

  1. Classification 预测离散类别,regression 预测连续数量,这是两者唯一的区别。Logistic regression 属于分类方法;它的名字来自"logistic function + linear regression"的组合,内部确实包含一个线性回归。

  2. y=β0+β1x1+…+βp−1xp−1+εy = \beta_0 + \beta_1x_1 + \dots + \beta_{p-1}x_{p-1} + \varepsilon。β0\beta_0 是所有 xj=0x_j = 0 时 yy 的值;βj\beta_j 是 xjx_j 增加 1 个单位时 yy 的变化,前提是其他输入保持不变;ε\varepsilon 是线性模型与某次实际观测值之间的随机误差。

  3. 最小化残差平方和 ∑i(yi−ŷi)2\sum_i (y_i - \hat y_i)^2。残差有正有负,直接相加会相互抵消,一条处处都错的直线也可能得到 0;平方后全部为正,不会抵消,而且处处可导,便于求闭式解。

  4. OLS 不对误差项做任何假设,只能给出 β\beta 的数值。Linear regression model 额外假设 ε∼N(0,σ2)\varepsilon \sim N(0,\sigma^2) 且各误差相互独立。它换来了统计推断的能力:可以算标准误、t 值、p 值,检验系数是否显著,评估估计的可靠程度。β\beta 的数值仍用 OLS 求得。

  5. 在正态误差假设下,对给定的 xx,y∼N(β0+∑jβjxj,σ2)y \sim N(\beta_0 + \sum_j\beta_jx_j, \sigma^2),所以模型给出的 β0+∑jβjxj\beta_0 + \sum_j\beta_jx_j 是 yy 的期望值,实际观测值等于期望值加随机噪声。图中三点:钟形中心都在直线上(零均值);钟形宽度相同(常数方差);观测点散落在钟形范围内(观测值 = 期望值 + 扰动)。

  6. Multiple R² 衡量输出的总变异中被模型解释的比例;Adjusted R² 在此基础上对变量个数施加惩罚。加入任何变量(包括无关变量)都不会让 R² 下降,只看 R² 会诱导人不停加变量、导致 overfitting;Adjusted R² 在新变量贡献不足时会下降,所以比较不同规模的模型时更公平。

  7. 加 4−1=34 - 1 = 3 个 binary 变量,以其中一个季节为基准。加 4 个时,4 列之和恒等于 1,与截距列完全相同,产生完全共线,OLS 有无穷多个解(哑变量陷阱)。按字母顺序编为 1–4,会凭空引入顺序和等间距,并强迫四个季节的效应落在一条直线上,结论还会随编号方式改变。

  8. "Linear" 指 yy 对系数 β\beta 是线性的,特征可以是原始变量或其变换。(a) 是,x2x^2 只是一个新特征;(b) 是,logx\log x 是变换后的特征;(c) 不是,β1\beta_1 出现在指数上。

  9. 三项:线性(outcome 对每个 input 作图)、残差零均值与常数方差(residuals vs fitted 图)、正态性(直方图或 Q-Q plot)。喇叭形说明方差随预测值增大,违背常数方差,常用的修正是变换输出(如取 logy\log y);拱形说明残差均值随预测值系统变化,通常是漏了非线性项,修正方法是加入平方项等新变量或变换输入。

  10. 点几乎都落在 qqline 画出的参考直线上,说明残差服从正态分布;点明显偏离直线(如两端弯曲成 S 形),说明不服从正态分布。

  11. Logistic regression 要输出概率,范围是 (0,1);它内部的线性函数输出范围是 (−∞,∞)(-\infty,\infty)。Logistic function 把后者映射到前者。两层结构:第一层是线性回归 y=β0+∑jβjxjy = \beta_0 + \sum_j\beta_jx_j;第二层是 logistic 外壳 P=ey/(1+ey)P = e^y/(1+e^y)。
